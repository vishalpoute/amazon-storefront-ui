# Amazon-Inspired Storefront UI

A static storefront inspired by Amazon, built to practice HTML and CSS layouts.

## Features

- Navigation and search-bar layout
- Product category cards
- Responsive styling and image assets

## Stack

HTML · CSS

## Run locally

Open `index.html` in a browser. The repository contains a static HTML/CSS interface.

## Project status

This is a frontend learning project, with no checkout, payment processing or backend. Amazon branding belongs to its owners.
